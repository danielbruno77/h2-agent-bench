You have never seen this project. Read only `README.md`, top to bottom, once. Then answer in this order:

1. In one sentence, what does this repository do?
2. What is the headline result, with its numbers, as you understood it?
3. What would you type to run it, copied exactly from the README? Say where you would stop because
   something is missing or unclear.
4. The three sentences that confused you most, quoted, with one line each on why.
5. Anything that reads as a claim without evidence.

Do not read any other file. Do not suggest rewrites; report what a stranger experienced.
