# h2-agent-bench

Verifier-graded benchmark of hydrogen CFD tasks in OpenFOAM, with the agent
harness that attempts them, baselines for frontier models, and the trajectories
released as training data.

**Headline:** _(filled on Day 9)_ Frontier models solve N of 9 tasks when every
submission is re-meshed and re-solved.
