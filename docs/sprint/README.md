# Sprint briefs

One file per day, `day01.md` to `day15.md`, loaded by `/day N` in Claude Code. Each brief has the goal,
the timed blocks, what is never delegated to the model, the day's judging drill, and the done-when list
that `/eod N` checks. The full step-by-step guide lives in the planning doc; these are the versions that
fit in a context window.
